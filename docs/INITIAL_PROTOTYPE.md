# AON 오늘의 센터

AON 운동센터의 **업무 대문과 블로그 발행 전 결과물**을 확인하는 시안입니다.

현재 버전은 가상 업무만 포함합니다. 실제 센터 회원정보, 운영 계정, 예약, 업무 데이터베이스와 연결하지 않았습니다.

## 실행

Python 3이 설치된 환경에서 저장소 폴더를 열고 실행합니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/`을 엽니다. 서버를 중지하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

- `index.html`: 오늘의 센터, 업무 등록·수정·검색·필터, 가상 일정
- `blog.html`: 예시 원고·이미지·근거·검수·다운로드

## 저장 방식과 현재 범위

- 업무 변경은 **현재 브라우저의 localStorage**에 저장됩니다.
- 다른 컴퓨터, 브라우저, 직원과 업무 데이터가 동기화되지 않습니다.
- 예시 기준일은 2026-11-18로 고정되어 있습니다.
- `예시 초기화`는 이 시안의 브라우저 저장값만 초기화합니다.
- 로그인, 직원별 권한, 공용 데이터 저장소, 백업·복원은 아직 구현하지 않았습니다.
- GitHub에 코드가 보관된 것과 실제 센터용 서비스가 운영되는 것은 별도 단계입니다. 이 초기본은 공개 사이트 배포와 자동 게시를 설정하지 않습니다.

## 블로그 예시

**운동은 꼭 30분씩 해야 할까요? — 짧게 나눠 시작하는 운동 이야기**

발행 전 형태를 보여 주는 원고, 제목 썸네일, 설명 이미지, 편집 가능한 Word, 복사할 본문, 출처·검수 기록을 포함합니다.

- 원고·자료: `content/`
- 이미지와 생성 기록: `assets/`
- Word와 다운로드 ZIP: `deliverables/`
- Word·본문·이미지는 시안에서 검토한 원본을 그대로 보존했습니다.
- ChatGPT가 작성·검수한 시연용 결과물이며 C.C 검수나 최종 발행 승인을 뜻하지 않습니다.

## 검증

외부 패키지를 설치하지 않고 로컬 연결을 확인할 수 있습니다.

```sh
python scripts/validate.py
```

검증 범위는 HTML의 로컬 링크·이미지·파일 존재 여부, ZIP 무결성, DOCX 내부 구조입니다. 외부 웹페이지의 현재 상태나 운영 서버 연결을 확인하는 검사는 아닙니다.

## 다음 구현 범위

실제 사용 전에는 로그인·권한과 공유 저장 방식, 업무 데이터 보존·복구, 센터 운영 흐름을 정해야 합니다. 블로그 자동작성 전체 실행과 발행 승인도 별도 확인 대상으로 둡니다.
