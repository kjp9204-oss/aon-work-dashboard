# 예시 원고 근거와 검토 기록

기준일: 2026-11-18 KST
대상: 「운동은 꼭 30분씩 해야 할까요?」 / 짧게 나눠 시작하는 운동 이야기
작성: ChatGPT 예시 원고. C.C의 실제 집필·검수 완료 또는 운영 자동화 성공으로 표시하지 않는다.

## 독자와 적용 범위

활동 시간이 부족하거나 운동을 시작하려는 일반 성인. 특정 질환의 재활 계획, 수술 후 운동량, 임산부·어린이·고령자 맞춤 처방은 다루지 않는다. 생활 속 5분 걷기는 설명용 예시이며 검증된 최소 효과 용량으로 제시하지 않는다.

## 자료 선택 과정에서 제외한 것

- NIDDK의 Tips for Starting Physical Activity 본문에는 ‘적어도 10분씩’이라는 구형 조건이 남아 있었다. 이번 원고의 짧은 활동 기준은 HHS 지침 Q&A를 사용했다.
- WHO 2020 지침 논문은 검색 결과에서 권장량을 확인했지만 PMC 직접 열람은 보안 확인 화면, BMJ는 403이었다. WHO 지침 PDF도 403이어서 ‘전문 검증 완료’로 쓰지 않았다. 공개 본문에는 직접 읽은 공식 WHO 발표문과 HHS Q&A만 관련 자료로 실었다.
- WHO 최신 fact sheet도 열었으나 이번 문장에 불필요한 자료 수를 늘리지 않기 위해 참고문헌에서 제외했다.

## 자체 검토

- 도입: 실제 회원을 만들지 않고 흔한 생활 상황과 질문으로 시작.
- 핵심: 짧은 활동의 가치와 주간 권장량을 구분. ‘5분이면 충분’·‘30분과 동등’ 없음.
- 과학: 관찰연구의 관련성과 인과관계를 구분. 연구 숫자는 확인한 표본수만 사용.
- 안전: 개인차·점진적 시작·증상 시 평가 안내 포함.
- CTA: 독자가 오늘 정할 행동 하나로 마무리. 예약·등록 유도 없음.
- 센터: 운영시간·비용·효과·우월성·임의 사례·직함을 만들지 않음.
- 저자·검수 상태: ChatGPT가 만든 시안용 원고. C.C 검수와 김재필의 발행 승인은 아직 없음.
- 다음: 감독 독립 검수 → 이미지·캡션과 본문 대조 → Word/HTML 동일 내용 확인 → 사용자 검토. 실제 게시 여부는 별도 기록.

## 이미지 지시와 주장 경계

- 대표 이미지: 일상 속 성인 걷기 장면. 실제 고객·실제 센터 촬영으로 표현하지 않는다. 제목과 부제를 그대로 사용한다.
- 설명 이미지: ‘짧게 시작 → 몸의 반응 확인 → 활동량 늘리기’ 세 단계. 특정 질환이 낫거나 체형이 교정되는 전후 이미지를 사용하지 않는다.
- 5분 숫자를 넣으면 ‘시작의 예시’ 문구를 가까이 표시한다. 150~300분은 ‘일반 성인·중강도 유산소·주당’ 조건을 함께 표시한다.
