# AON 오늘의 센터

에이온 운동센터의 할 일·담당자·일정·진행 상태를 관리하는 비공개 업무 대문입니다.

**접속 주소:** https://aon-work-dashboard.jaepilkim.chatgpt.site

현재는 소유자 계정으로 로그인한 뒤 사용할 수 있습니다. GitHub는 소스 보관용이며, 로그인·DB·실행 서비스는 Sites에서 운영됩니다.

## 사용할 버전

- `server/`: 실제 배포한 로그인·D1 서버 저장 버전. 자세한 실행법은 [서버 README](server/README.md).
- 저장소 루트의 `index.html`·`dashboard.js` 등: 승인받은 초기 디자인 시안. 가상 자료와 브라우저 로컬 저장 방식으로 보존했습니다. 운영용으로 열지 마세요.
- [초기 시안 안내 보관](docs/INITIAL_PROTOTYPE.md)

## 구현한 기능

- 업무 등록·수정, 담당자 직접 입력, 마감·상태 관리
- 검색과 담당자·상태·내가 등록한 업무 필터
- 센터 일정 등록·수정, 이번 주 달력과 전체 일정
- 한국 시간 기준 날짜와 서버 저장 상태
- 동시 수정 충돌 차단, 중복 요청 재시도 보호
- 로그인 만료 시 작성 내용을 유지한 재로그인·재저장
- 업무·일정 JSON 백업 다운로드
- 블로그 발행 전 예시의 원고·이미지·근거·검수·Word 내려받기

실제 운영 DB는 비어 있는 상태에서 시작합니다. 로컬 기능 검증용 자료는 운영에 이관하지 않았습니다. 직원 초대·역할별 권한·회원 DB 연동·AI 자동 집필·네이버 자동 발행은 이번 범위에 포함하지 않았습니다. C.C 검수 완료로 표기하지 않습니다.
